# Lab 1 - Diseño de Lenguajes

Analizador léxico desarrollado con Flex para reconocer tokens en diferentes lenguajes de programación.

## Descripción

Este laboratorio implementa un lexer utilizando Flex que identifica y clasifica tokens como identificadores, números, operadores, cadenas y comentarios.
